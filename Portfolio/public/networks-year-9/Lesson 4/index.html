Servers

Servers are powerful computers dedicated to carrying out a service — such as the delivery of web pages. They don't have their own screens or keyboards; they just sit in racks doing their job 24/7.

💡 A server = a powerful computer dedicated to providing a service — like delivering web pages, storing files or printing.
🏢 A school or business may keep a cabinet on site. The really big services keep their servers in data centres — more on those shortly!

The client-server model

In the client-server model, computers called clients request services from a central server, and the server responds. Here's a small local network — like your school's — with four clients connected to one server.

💡 Clients don't depend on each other — one can be off or broken and the rest work as normal. But everyone depends on the server.

Data centres

Where do the servers behind the world's websites and apps actually live? In data centres — huge buildings that contain thousands of servers, stacked in row after row of cabinets.

🌡️ Data centres need industrial cooling, backup power generators and tight security — because millions of people rely on the servers inside, 24 hours a day.

Peer-to-peer networks (P2P)

In a peer-to-peer network there is no central server. Each computer is an equal — a peer — and each peer can share its resources (printers, scanners, storage) with the others.

💡 Click a computer to switch it off, or click a cable to break it — then run the demos and see what still works. Notice there's no server anywhere!

💡 Compare it with client-server: when the server failed, the whole network was useless. In P2P, a broken computer or cable only takes out that one part — everything else keeps working, because there is no single point of failure.

Side-by-side comparison

Click each row to compare client-server vs peer-to-peer. The green badge shows which one wins that category.

🗄️ Client-server
✅ Easy

Everything is stored in one central place — back up the server and you've backed up everyone.

🤝 Peer-to-peer
⚠️ Hard

Every computer needs its own backup system.

🗄️ Client-server
✅ Easier to secure

There is one central location to protect and keep secure.

🤝 Peer-to-peer
⚠️ Less secure

Every computer needs to be secured individually.

🗄️ Client-server
✅ Central control

The whole network can be administered from one place — the server.

🤝 Peer-to-peer
⚠️ Hard to manage

There is no central point to the network, so each peer is managed separately.

🗄️ Client-server
⚠️ Expensive

A powerful, dedicated server has to be bought — and maintained.

🤝 Peer-to-peer
✅ Cheap

No dedicated server hardware needs to be bought — existing computers do the work.

🗄️ Client-server
⚠️ Risky

If the server fails, no-one can access the services it offers.

🤝 Peer-to-peer
✅ Resilient

If one computer fails, files on the other computers are still available.

🗄️ Pick client-server when…

You're a school or business that needs central backups, security and administration — and can afford a server.

🤝 Pick peer-to-peer when…

You have a small home or office network and just want to share printers and files cheaply, without buying a server.

Cloud computing

The Cloud is essentially another name for the Internet. "Cloud computing" covers services that are offered via the Internet instead of running on your own computer.

☁️ When your file is "in the cloud", it isn't floating in the sky — it's sitting on a server in a data centre, reached through the client-server model you've just learned about.

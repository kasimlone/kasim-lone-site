why binary?

Why does everything become 1s and 0s?

Every computer is built from billions of tiny switches called transistors. A switch has only two possible states: on or off. That's a perfect match for the binary number system, which has only two digits: 1 and 0.

  • 1 = switch on / current flowing / magnetised north / laser reflected.
  • 0 = switch off / no current / magnetised south / laser absorbed.

Because computers can only store on/off, every piece of data — text, images, sound, video, anything — must first be converted into binary before it can be stored or processed.

💡 Analogy: the accelerator pedal

A car's accelerator has hundreds of positions between 0 and 100 mph. A computer only has two: 0 mph (0) or 100 mph (1). Anything in between has to be built up from lots of ons and offs.

units

The units of data storage

A single 1 or 0 is called a bit. That's the smallest unit of data a computer can store. It isn't very useful on its own, so bits are grouped into bigger units. These are the units you must know for GCSE:

UnitSymbolSizeExample
Bitb1 or 0—
Nibble—4 bitsHalf a byte
ByteB8 bitsA single character (e.g. "A")
Kilobyte (KB)KB1,000 BA small text file
Megabyte (MB)MB1,000 KBA music file
Gigabyte (GB)GB1,000 MBA HD movie
Terabyte (TB)TB1,000 GBA large hard drive
Petabyte (PB)PB1,000 TBA large data centre
💡 Examiner tip

Technically, 1 KB = 210 = 1024 bytes. In GCSE we simplify and use 1,000 to make the maths easier. Always use 1000 unless the question says otherwise.

converting

Converting between units

There are only two rules you ever need:

  1. Going between bits and bytes? Multiply or divide by 8.
  2. Going between any bigger units (B → KB → MB → GB → TB → PB)? Multiply or divide by 1000.

Rule of thumb:

  • Going up a unit (smaller → bigger): divide.
  • Going down a unit (bigger → smaller): multiply.
✏️ Worked example 1

Convert 2000 KB into MB.

KB → MB is going up, so divide by 1000.
2000 ÷ 1000 = 2 MB

✏️ Worked example 2

Convert 2 TB into GB.

TB → GB is going down, so multiply by 1000.
2 × 1000 = 2000 GB

✏️ Worked example 3

Convert 24 bits into bytes.

bits → bytes is going up, so divide by 8.
24 ÷ 8 = 3 bytes

Try it yourself

Q1. How many bytes are in 6 nibbles?

6 nibbles × 4 bits = 24 bits. 24 ÷ 8 = 3 bytes.

Q2. How many bits are in 5 kilobytes?

5 KB × 1000 = 5000 bytes. 5000 × 8 = 40,000 bits.

Q3. Tick the equivalents: 2000 gigabytes = ? terabytes

2000 GB ÷ 1000 = 2 TB.

capacity

Data capacity & calculating how much fits

Data capacity is the maximum amount of information a storage device can hold. If you know the capacity and the size of one file, you can work out how many files the device can store.

DeviceTypical capacity
CD700 MB
USB flash drive16 GB – 256 GB
SSD128 GB – 2 TB
HDD500 GB – 8 TB

The three-step method

  1. Know the capacity of the device.
  2. Convert so the file size and capacity are in the same units.
  3. Divide capacity ÷ file size = number of files.
✏️ Worked example — Lyla's images

Lyla creates images that are 3 MB each. She stores them on a 6 GB USB stick. How many images can she save?

Step 1 — convert to the same units. 6 GB = 6 × 1000 = 6000 MB.
Step 2 — divide. 6000 ÷ 3 = 2000 images.

practice

Exam-style practice

Q1. A memory card has a capacity of 32 GB. Each video is 400 MB. How many videos fit?

32 GB = 32,000 MB. 32,000 ÷ 400 = 80 videos.

Q2. A text file is 5,000 characters long using Extended ASCII (1 byte per character). What is the file size in KB?

5000 × 1 byte = 5000 bytes = 5000 ÷ 1000 = 5 KB.

Q3. A CD has 700 MB capacity. A song is 5 MB. How many songs fit on the CD?

700 ÷ 5 = 140 songs.

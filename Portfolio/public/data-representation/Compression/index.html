why compress?

Why do we compress files?

Compression means reducing the size of a file so it takes up less space on secondary storage.

Two big reasons:

  • Storage. Fit more files on the same device — phones, tablets, laptops, servers.
  • Speed. Send data faster across a network — quicker uploads, downloads and streaming.

There are two methods of compression:

  • Lossy — throws data away.
  • Lossless — reorganises data so the original can be recovered.

lossy

Lossy compression

  • Data is lost to reduce the file size.
  • Irreversible — the original file cannot be recovered from the compressed version.
  • Can shrink files dramatically, but at the cost of quality.
  • Only suitable when a drop in quality is acceptable — images, video and sound.

Example: in a photograph, lossy compression groups similar colours together, reducing the total number of colours without a big visible change.

✏️ Real example

Original JPG: 824 KB
50% lossy compression: 76 KB (looks nearly identical)
80% lossy compression: 38 KB (quality noticeably drops)

lossless

Lossless compression

  • Data is encoded, not lost.
  • Reversible — the original file can be recovered exactly.
  • Reduces file size, but not as much as lossy.
  • Used where any loss of quality is unacceptable — documents, code, spreadsheets, some images.

A common technique: look for patterns and repetition. Repeating characters can be replaced with a single character + a count.

✏️ Example — run-length encoding

"EEEEE" → E5. Same information, fewer characters. When the file is opened, the algorithm reverses this to get "EEEEE" back.

When you open a compressed document, the software decompresses it automatically. Formats like .docx, .pdf, .zip and .png all use lossless compression.

practice

Exam-style practice

Q1. Give two reasons why files are compressed.

1) To save storage space so more files can be stored on a device. 2) To reduce transfer time when sending files over a network.

Q2. Sarah records an audio file and emails it to a friend for proofing. Explain two reasons why using lossy compression is beneficial. [4]

Lossy will decrease the file size [1] so it can be sent via email quicker [1].
Lossy means data is lost [1] but the difference in sound quality is unlikely to be noticed by humans [1].

Q3. Explain why lossless compression is preferred for word-processed documents.

Lossless is reversible so the document is returned exactly to its original state — no words or characters are lost, which would be unacceptable in a document.

Q4. Describe how lossless compression can reduce the size of a text file.

An algorithm looks for patterns and repetition. Repeating characters can be replaced with a single character followed by the number of occurrences. For example "EEEEE" becomes "E5". When opened, the algorithm reverses this to restore the original.

bitmap vs vector

Two ways to store an image

Bitmap

  • Made up of tiny squares called pixels ("picture elements").
  • Each pixel is stored as a unique binary code for its colour.
  • The more colours and detail, the more binary that has to be stored.
  • A typical bitmap is a photograph (JPG, PNG).

Vector

  • Made up of mathematical equations and points.
  • Only the maths is stored — no pixels.
  • To store a circle you'd store the centre point and the radius.
  • Vectors are infinitely scalable — perfect for logos used on both a pen and a billboard.
⚠️ Exam focus

In the exam all image questions are about bitmaps. You just need to know what a vector is — after that, focus on pixels, resolution and colour depth.

resolution

Resolution

Resolution is the total number of pixels that make up a bitmap image. It's calculated by multiplying the width by the height (in pixels).

ExampleResolutionTotal pixels
Small image100 × 10010,000
Medium image500 × 500250,000
HD monitor1920 × 10802,073,600
4K TV3840 × 2160~8.3 million

The higher the resolution, the more detail in the image — but also the bigger the file size.

💡 Resolution in real life

"1080p" (HD), "1440p" and "4K" all describe resolution. Bigger numbers = more pixels = sharper image = larger file.

colour depth

Colour depth

Colour depth is the number of bits stored per pixel. It decides how many different colours each pixel can be.

With n bits per pixel, there are 2n possible colours:

Colour depthColours availableExample use
1 bit2 (black & white)Retro pixel art
2 bits4Very limited colour
4 bits16Old computer games
8 bits256Simple graphics
24 bits16,777,216 ("true colour")Photographs
1 bit2 colours
2 bits4 colours
4 bits16 colours
8+ bits256+ colours
💡 Quality vs file size

A higher colour depth means more colour detail — but more bits per pixel means a bigger file. There's always a trade-off between quality and size.

file size

Calculating image file size

📐 Formula

Size (bits) = Resolution (W × H) × Colour depth (bits per pixel)

To get bytes, divide by 8. To get KB, divide by 1000. To get MB, divide by another 1000.

✏️ Worked example

An image is 500 × 500 pixels with a colour depth of 24 bits. Calculate the file size in KB.

Step 1 — pixels: 500 × 500 = 250,000
Step 2 — bits: 250,000 × 24 = 6,000,000 bits
Step 3 — bytes: 6,000,000 ÷ 8 = 750,000 bytes
Step 4 — KB: 750,000 ÷ 1000 = 750 KB ✅

What happens when things change?

  • Higher resolution → more pixels → more bits → larger file.
  • Higher colour depth → more bits per pixel → larger file.
  • Both increase the visual quality of the image.
  • You always have to balance quality against file size.

metadata

Metadata — data about data

Metadata is extra information stored alongside an image file. It isn't needed to display the image, but it gives context and helps organise it.

MetadataWhat it stores
AuthorWho created the image
Date & timeWhen the image was taken/created
LocationWhere the image was taken (GPS)
Width & heightThe image resolution
Colour depthBits per pixel
✏️ Worked example

A parent takes a photograph while on holiday. Identify three pieces of metadata that might be stored.

Location, Author, Resolution (or Date/Time, Colour depth — any three).

practice

Exam-style practice

Q1. Define the term pixel.

The smallest element (a single square) of a bitmap image.

Q2. If an image has a colour depth of 2 bits, how many colours can it represent?

22 = 4 colours

Q3. Describe the impact of changing an image's resolution from 500 × 500 to 1000 × 1000.

The image quality would be higher (more pixels), and the file size would be larger (4× the number of pixels).

Q4. An image is 200 × 100 pixels with a colour depth of 8 bits. Calculate the file size in KB.

200 × 100 = 20,000 pixels. 20,000 × 8 = 160,000 bits. 160,000 ÷ 8 = 20,000 bytes = 20 KB.

Q5. A logo is being used on both a business card and a billboard. Should it be stored as a bitmap or a vector? Explain.

Vector. Vector images are stored as mathematical equations, so they can be scaled to any size without losing quality. A bitmap would become pixelated on the billboard.

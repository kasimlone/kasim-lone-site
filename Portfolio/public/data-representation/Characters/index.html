character sets

What is a character set?

Computers can only store binary. So every letter you type on a keyboard has to be converted into a unique binary number first.

A character set is a defined list of characters, where every character has been given a unique binary code. Without a character set, one computer might store 01000001 and another might read it as something completely different.

🔑 Key facts
  • Each character has a unique binary code.
  • Codes are ordered logically — the code for 'B' is one more than the code for 'A'.
  • A character set is a standard so systems can share text reliably.
  • The number of characters a set can store depends on the number of bits used: n bits → 2n characters.

Two character sets you must know at GCSE:

  • ASCII — American Standard Code for Information Interchange
  • Unicode — Universal Character Encoding

ASCII

ASCII

ASCII was one of the earliest character sets and is still widely used. It uses 7 bits per character, giving 27 = 128 possible characters.

What ASCII can store

  • A–Z (uppercase), a–z (lowercase)
  • 0–9 (digits)
  • Common punctuation: !, @, #, $, %, &, ?, .
  • Non-printable control codes (e.g. tab, newline)

Extended ASCII

Extended ASCII uses 8 bits per character (28 = 256 characters). This adds room for maths symbols and characters like ©.

💡 In the exam

The exam expects 8-bit Extended ASCII for all binary representations of characters. So if you're asked to write 'A' in binary, use 01000001 (8 bits), not 1000001 (7 bits).

💡 Anchor codes

Just remember A = 65 and a = 97. Every other letter is one more (B = 66, C = 67…). The difference between an uppercase and lowercase letter is always 32.

✏️ Worked example

The computer stores text using ASCII. Part of the set is: E=69, F=70, G=71, H=72. Identify the character represented by 76.

Counting up: 72=H, 73=I, 74=J, 75=K, 76=L ✅ (must be capital — lowercase would be much higher).

Unicode

Unicode

ASCII was designed for English. It can't represent Greek, Arabic, Chinese, Japanese, emoji, or thousands of modern symbols. Unicode was created to fix that.

  • Unicode uses a minimum of 16 bits per character.
  • 216 = 65,536 unique codes.
  • Can represent characters from all major languages around the world.
  • Can store special symbols like emoji 😀.
💡 Compact fact

Unicode is a superset — the first 128 codes match ASCII exactly. So Unicode is backwards compatible with ASCII.

practice

Exam-style practice

Q1. A computer stores text using ASCII. Part of the set: E=69, F=70, G=71, H=72. Identify the character with code 75.

K (72 = H, 73 = I, 74 = J, 75 = K)

Q2. Identify a character set other than ASCII.

Unicode

Q3. Give one benefit and one drawback of Unicode compared to ASCII.

Benefit: can store many more characters (65,536 vs 128), including emoji and other languages. Drawback: each character uses more storage (16 bits vs 8), so files are bigger.

Q4. A text file contains 500 characters using Extended ASCII. What is the file size in bytes?

500 × 1 byte = 500 bytes.

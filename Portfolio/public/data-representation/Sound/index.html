sampling

How sound becomes binary

Sound in the real world is analogue — a smooth, continuous wave of air pressure. But computers can only store binary. So sound has to be converted from analogue to digital.

This process is called Analogue to Digital conversion (A2D).

  1. The height (amplitude) of the wave is measured at regular time intervals. Each measurement is called a sample.
  2. Each sample is stored as a binary value.
  3. Using all these samples, the computer builds a stepped digital version of the original wave.
  4. The digital wave is stored on secondary storage and can be played back at any time by reversing the process.
💡 Analogy: dot-to-dot

Sampling is like drawing a smooth curve as a dot-to-dot picture. The more dots, and the more accurately each dot is placed, the closer your dot-to-dot looks to the original curve.

sample rate

Sample rate

Sample rate is the number of samples taken per second of the analogue wave. It's measured in Hertz (Hz). 1 Hz = 1 sample per second.

SourceTypical sample rate
Telephone~16 / 22 kHz
Audio CD44.1 kHz (44,100 samples/s)
DVD48 kHz

Higher sample rate → the digital wave is closer to the original → better quality sound. But it also means more data per second → larger file size.

💡 That's why phone hold music sounds bad

Telephone systems use a low sample rate to save bandwidth. That's why hold music always sounds compressed and hollow — the wave is being reconstructed from too few samples.

bit depth

Bit depth

Bit depth is the number of bits stored per sample. It decides how accurately each sample's height can be measured.

  • 1 bit → 2 possible amplitude levels (very inaccurate).
  • 8 bits → 256 levels.
  • 16 bits → 65,536 levels (CD quality).

A higher bit depth → a bigger range of amplitudes → better sound quality — but more data per sample → larger file size.

💡 Bit depth vs colour depth

Bit depth in sound and colour depth in images measure the same idea — how many bits are stored per sample/pixel. The higher the number, the more precise each value.

file size

Calculating sound file size

📐 Formula

Size (bits) = Sample rate × Duration (seconds) × Bit depth

To get bytes, divide the answer by 8.

✏️ Worked example

A recording is made at 10 samples/second, 4 bits per sample, lasting 30 seconds. Calculate the file size in bytes.

Step 1 — bits: 10 × 30 × 4 = 1,200 bits
Step 2 — bytes: 1,200 ÷ 8 = 150 bytes ✅

Effect on quality and file size

FactorHigher = qualityHigher = file size
Sample rateMore detail, closer to originalMore samples/s → more data
Bit depthMore precise amplitude, bigger rangeMore bits per sample → more data

practice

Exam-style practice

Q1. Describe how an analogue sound wave is converted into digital form. [3]

1) The analogue sound wave is sampled.
2) The amplitude (height) of the wave is measured…
3) …at set/regular intervals.
Each sample is stored as a binary value.

Q2. A song is recorded at 44,100 Hz with a bit depth of 16 bits, lasting 4 minutes. Calculate the file size in MB.

Duration in seconds: 4 × 60 = 240s. Bits: 44,100 × 240 × 16 = 169,344,000 bits. Bytes: ÷ 8 = 21,168,000 bytes. MB: ÷ 1,000,000 ≈ 21.17 MB.

Q3. Explain the effect of doubling the sample rate on quality and file size.

Quality would improve because more samples per second means the digital wave is closer to the original analogue wave. File size would double, because twice as much data is stored per second.

Q4. Explain why telephone hold music often sounds poor quality.

Telephone systems use a low sample rate (around 16 kHz), so fewer samples are taken per second. This means the digital wave doesn't match the original analogue wave as closely, giving a lower quality sound.

🔊 what is sound?

Sound is a wave

Sound in the real world is analogue — a smooth, continuous wave of air pressure. Press play to hear a pure 440 Hz sine wave (the note A above middle C). This is what your ears hear before any computer touches it.

ready

💡 Real sound isn't this clean

A pure sine wave sounds "clean" because it's a single frequency. Real music and voice are many waves added together — but every one of them still has to be digitised the same way.

A2D

How sound becomes binary

Computers can only store binary. So sound has to be converted from analogue to digital — a process called Analogue to Digital conversion (A2D).

  1. The height (amplitude) of the wave is measured at regular time intervals. Each measurement is called a sample.
  2. Each sample is stored as a binary value.
  3. Using all these samples, the computer builds a stepped digital version of the original wave.
  4. The digital wave is stored on secondary storage and can be played back at any time by reversing the process.
💡 Analogy — dot-to-dot

Sampling is like drawing a smooth curve as a dot-to-dot picture. The more dots, and the more accurately each dot is placed, the closer your dot-to-dot looks to the original curve.

💡 Watch (and listen) for
  • Push sample rate up — the digital wave hugs the analogue wave more closely, and the sound becomes smoother.
  • Drop bit depth to 2 or 3 — you'll hear a harsh "8-bit game" crunch as the amplitudes are forced into a few coarse levels.
  • Both increase quality and file size.

sample rate

Sample rate

Sample rate is the number of samples taken per second of the analogue wave. It's measured in Hertz (Hz). 1 Hz = 1 sample per second.

SourceTypical sample rate
Telephone~8 kHz
Audio CD44.1 kHz (44,100 samples/s)
DVD48 kHz

Higher sample rate → digital wave closer to the original → better quality. But more data per second → larger file size.

💡 Why phone hold music sounds bad

Telephone systems use a low sample rate to save bandwidth. The reconstructed wave loses everything above about 4 kHz — that's why hold music always sounds hollow and compressed.

bit depth

Bit depth

Bit depth is the number of bits stored per sample. It decides how accurately each sample's height can be measured.

  • 1 bit → 2 possible amplitude levels (very inaccurate).
  • 8 bits → 256 levels.
  • 16 bits → 65,536 levels (CD quality).

A higher bit depth → bigger range of amplitudes → better sound quality — but more data per sample → larger file size.

💡 Bit depth vs colour depth

Bit depth in sound and colour depth in images measure the same idea — how many bits are stored per sample/pixel. The higher the number, the more precise each value.

file size

Calculating sound file size

file size (bits) = sample rate × duration (s) × bit depth

Then divide by 8 for bytes, by 1024 for kilobytes (KiB), and so on.

✏️ Worked example

A recording is made at 10 samples/second, 4 bits per sample, lasting 30 seconds. Calculate the file size in bytes.

Step 1 — bits: 10 × 30 × 4 = 1,200 bits
Step 2 — bytes: 1,200 ÷ 8 = 150 bytes ✅

🎉 What you should remember

  • Sample rate = samples per second (Hz). Higher = closer to the analogue wave.
  • Bit depth = bits per sample. Higher = more accurate amplitude.
  • File size (bits) = sample rate × duration × bit depth. Divide by 8 for bytes.
  • Low sample rate → hollow, muffled sound. Low bit depth → crunchy, quantised sound.
